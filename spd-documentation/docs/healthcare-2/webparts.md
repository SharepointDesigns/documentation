| Sl No. | Webpart Name        | Type    | Description                                                                                                                                                |
| ------ | ------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | Welcome Banner       | Webpart | Serves as a modern landing banner for an intranet or organizational home page. It displays a personalized welcome section with date and time, highlights key messages such as the organization’s vision, and provides quick‑access navigation tiles for frequently used links. The responsive design with a large background image enhances visual appeal while enabling users to access important resources quickly and efficiently.                                           |
| 2     | Document Content      | Webpart | Provides a structured, card‑based view of document libraries and folders, enabling users to quickly access categorized organizational content. Each tile displays the folder name, file count, and notification indicators, helping users stay informed about updates and new documents. The clean, responsive layout improves document discoverability and enhances overall intranet usability.
| 3    | Announcement | Webpart | Displays important alerts and organizational messages in a clean, scrolling banner format. It highlights key announcements with quick navigation controls and a “Read More” option, ensuring users stay informed about critical updates without disrupting their workflow.                                            
| 4    | News                | Webpart | **Focused Updates:** Keep everyone informed with concise company news. **Clear Presentation:** News displayed in an easy-to-read, minimalist format.       |
| 5     | Organization Chart | Webpart | Enables users to quickly search and connect with colleagues through an integrated employee directory. It displays profile details such as name and role, along with quick actions for email or messaging, making internal communication and collaboration faster and more efficient.                           |
| 6     | Employee Spotlights     | Webpart | Highlights and celebrates employee achievements in a visually engaging card and carousel format. It displays recognized team members along with role details, nomination information, and appreciation messages, and allows colleagues to send greetings—helping foster a positive, appreciative workplace culture.  |
| 7    | Take a Breath    | Webpart | Provides a simple, guided breathing exercise using a calming animated visual. It helps users pause, relax, and reset during the workday, promoting mindfulness and mental well‑being directly within the intranet experience.  |
| 8    | Gallery    | Webpart | Displays images in a responsive, category‑based layout, allowing users to easily browse and filter visual content. It is ideal for showcasing events, activities, or organizational moments, with intuitive navigation controls that enhance user engagement and content discovery.  |

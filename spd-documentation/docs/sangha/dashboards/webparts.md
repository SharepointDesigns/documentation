This page lists all web parts and extensions included across both packages in the Dashboard Suite.

---

## Intelligence Dashboard Package (`spd-intelligence-dashboard.sppkg`)

| Sl No. | Web Part Name          | Type     | Description                                                                                                                                                                                                                                                                                                                                                                             |
| ------ | ---------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | Intelligence Dashboard | Web Part | An AI-powered intranet command centre that gives administrators and content owners real-time visibility into site performance, content health, and engagement. It uses Microsoft Copilot and Microsoft Graph to surface analytics, trending topics, AI-generated article drafts, and actionable content suggestions — all from a single, configurable dashboard on any SharePoint page. |

## Personal Dashboard Package (`spd-personaldashboard.sppkg`)

| Sl No. | Web Part Name      | Type     | Description                                                                                                                                                                                                                                                                                                                                                                          |
| ------ | ------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1      | Personal Dashboard | Web Part | A personalised daily productivity hub that brings together each employee's most important Microsoft 365 information in one place. It displays today's calendar meetings with join links, active Planner tasks, real-time team presence, upcoming team birthdays, public holidays, and outstanding Viva Learning training assignments — all updated automatically on every page load. |

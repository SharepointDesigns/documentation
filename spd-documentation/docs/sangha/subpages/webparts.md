| Sl No. | Web Part Name            | Type    | Description                                                                                                              |
| ------ | ------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| 1      | Welcome Banner           | Webpart | Hero banner at the top of sub-pages with a background image, department name, and an optional announcement strip         |
| 2      | Featured News            | Webpart | Aggregates news posts from one or more SharePoint sites with search, sort, and category filtering                        |
| 3      | Common Tools             | Webpart | Quick-access link tiles with icons for tools and resources, with Standard and Accent Bar layout options                  |
| 4      | Document Contents        | Webpart | Surfaces documents from a SharePoint library in Film Strip, Grid, List, or Compact view with folder and category filters |
| 5      | Feedback                 | Webpart | Call-to-action banner with an image and a button linking to a feedback or support destination                            |
| 6      | Goals                    | Webpart | Displays department or team goals as icon cards with a title, description, and optional link                             |
| 7      | Newsletter               | Webpart | Showcases newsletter editions from a document library with cover images, a month filter, and an optional carousel        |
| 8      | The Team                 | Webpart | Displays team member or SME profiles with photos, roles, and an optional carousel                                        |
| 9      | Configure Site Sub Pages | Webpart | One-click setup wizard that provisions and configures sub-page structures (Departments, Employee Resources, Policies)    |

# Web Parts

DIY Intranet Home includes nine web parts and one extension. All web parts can be added to any modern SharePoint page independently.

| Sl No. | Web Part Name          | Type    | Description                                                                                                                                                                                                         |
| ------ | ---------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | **Welcome Banner**     | Webpart | Greets each employee by name with a live clock and a customisable background image. Includes a personal dashboard panel showing the user's meetings, tasks, and upcoming training from their Microsoft 365 account. |
| 2      | **Announcement**       | Webpart | Displays a rotating carousel of company announcements. Each announcement supports a clickable link, an expiry date for automatic removal, and an optional icon image.                                               |
| 3      | **Featured News**      | Webpart | Aggregates SharePoint news posts from one or more selected sites in a variety of layouts. Supports category filtering, search, sorting, RSS feed integration, and audience targeting.                               |
| 4      | **Common Tools**       | Webpart | A quick links panel for the apps and tools your team uses every day. Each link supports a title, URL, Fluent UI icon, and open-in option. Includes hover effects and two display styles.                            |
| 5      | **Employee Spotlight** | Webpart | Highlights upcoming birthdays, work anniversaries, and new joiners. Data is sourced automatically from Azure Active Directory or managed manually through the settings panel.                                       |
| 6      | **Org Chart**          | Webpart | Draws an interactive reporting hierarchy from Microsoft 365. Supports three view modes — your team, the full company, or another manager's team — with hover contact cards and reorderable direct reports.          |
| 7      | **Upcoming Events**    | Webpart | Shows company events and important dates from a SharePoint calendar list, a shared mailbox, or the logged-in user's Outlook calendar. Includes a full calendar view and event filtering by date range.              |
| 8      | **Facilities**         | Webpart | Showcases your organisation's offices and locations with photos, descriptions, and map links. Supports auto-scroll navigation and configurable display height.                                                      |
| 9      | **Message from CEO**   | Webpart | Displays a leadership message with a profile photo, designation, heading, and message body. The full message opens in a modal overlay panel when users click to read more.                                          |

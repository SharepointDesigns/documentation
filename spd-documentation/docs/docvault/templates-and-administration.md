# DocVault — Templates & Administration

## Templates & Libraries

The Templates screen carries your organisation's approved starting points. Cards tagged **Global** are available to every department; cards tagged with a department name are restricted to it. Cards tagged **Sample** are the built-in starters that ship with DocVault.

- **Upload template** — add a real Word, Excel, PowerPoint or PDF file and choose whether it is Global or scoped to one department.
- **Use template** — opens the new-document dialog with the template pre-selected. DocVault copies the template into the department library you choose, applies your metadata, assigns the next document number and opens the copy for editing.
- **New library** — register an additional department library with its own document-number prefix and default review cycle.

## Administration overview

The Admin screen carries five panels:

- **Data source & setup** — the Dev / Live toggle, the current mode badge, how many department sources are connected, and a link to run or re-run the Setup Wizard.
- **Branding** — theme colour, logo and welcome banner. See [Branding](#branding) below.
- **Documents by status** — a live bar chart of the whole repository.
- **Roles & permissions** — a reference matrix of the five DocVault roles and what each can do.
- **Retention & disposition rules** — the retention schedule reference for each record class.
- **Activity & audit log** — the most recent status changes across all libraries.

:::note
The Roles & permissions matrix and the Retention & disposition table document your governance model for auditors. They are reference views: actual permissions are managed in SharePoint, and retention is enforced by Microsoft Purview.
:::

## Branding

Only site administrators can change branding; everyone else sees the panel with a lock notice.

- **Primary theme colour** — one colour drives the whole portal: buttons, links, highlights and accents. Pick from eight presets, use the colour picker, or type a hex value.
- **Logo** — upload a PNG, JPG, SVG or WebP. Raster images are downscaled automatically. The logo appears in the top navigation, the footer and the activation screen. Reset to default removes it.
- **Welcome banner** — choose a solid colour or an image URL for the Home hero. Leave the colour blank to use the default DocVault gradient. A live preview sits beside the controls.

Select **Save branding**. Other pages pick up the change on their next load.

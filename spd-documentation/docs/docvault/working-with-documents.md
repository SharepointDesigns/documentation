# DocVault — Working with a Document

Selecting a document anywhere in DocVault opens its detail page. The header shows the title, status badge, document number, department, version and owner, followed by a four-stage progress tracker: **Draft → Manager → QA Review → Published**.

## The six tabs

| Tab | Contents |
| --- | --- |
| Overview | The full metadata grid, plus a banner stating whether external sharing is allowed for this classification |
| Version history | Every SharePoint version with its check-in remark, author and date. Each version can be opened in the browser or downloaded |
| Workflow | The stage tracker plus a timeline of approval events |
| Comments | Threaded comments. Type and press Enter or select Comment |
| Audit trail | Every version event plus document creation, newest first |
| Permissions | Who has access to this specific document, and at what level |

- - -

## Viewing, checking out and editing

- **Open** — opens the file read-only in Office for the web. No lock is taken, so anyone with read access can use it.
- **Check out** — takes an exclusive lock. An amber banner then names who holds the document.
- **Edit in browser** — appears once the document is checked out, and opens Office for the web in edit mode.
- **Check in** — asks for a remark before releasing the lock.

The check-in remark is mandatory. SharePoint cannot describe what changed between two versions, so the remark you write becomes the permanent record in the version history. A starting sentence is pre-filled; replace it with a real description of the change.
